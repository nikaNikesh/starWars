# Star Wars
A web application for exploring the Star Wars universe. Users can view information about characters, planets, and spaceships.

## Technologies used:

- JavaScript
- Bootstrap
- React
- React Hooks
- React-router-dom

## How to run?
1. Make sure you have [Node.js](https://nodejs.org/) installed.
2. Clone the repository.
3. Install dependencies:
### `npm install`
npm install
4. Run
### `npm start`
5. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
